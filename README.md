# IdeaForge-X

Folder layout:
  server.js, package.json, .env, public/index.html

Steps:
1. Install Node.js from nodejs.org (LTS)
2. Open a terminal in this folder and run:  npm install
3. Copy .env.example to .env and paste your Gemini key (aistudio.google.com/apikey)
4. Run:  npm start
5. Open http://localhost:3000

After you change .env, press Ctrl+C and run npm start again.
